# VisionPLC XY磁吸数字分拣台：步骤级实施手册

> 版本：V1.2（套装化硬件 + 当前进度对齐版）  
> 日期：2026-10-13  
> 平台：安路 PH1P35 / HX1P35A  
> 控制架构：片内 RISC-V MCU 指令调度 + FPGA视觉与硬实时运动控制  
> 最终演示载体：成品3018三轴平台、Z轴升降、24V电磁铁抓取带钢片数字块

## 0. 方案冻结与边界

为保证软件、机械和采购清单都能直接执行，本手册将最终项目固定为：

> 摄像头俯视识别最多8个数字块及其坐标，片内MCU把稳定视觉快照转换成搬运指令，FPGA运动模块驱动XY平台依次抓取数字块，并按照类别、位置或用户选择的规则放入目标区。

本项目不是传送带分拣机：数字块和目标托盘都放在固定的3018工作台上，由现成XYZ机构完成平面搬运和Z向取放，不采购传送带、滚筒、电机支架或光电门。

### 0.1 第一版必须实现

- 最多识别8个静态数字目标。
- 视觉结果连续3批稳定后才能锁定任务。
- MCU完成排序、像素到机械坐标变换和动作序列生成。
- FPGA完成三轴回零、绝对定位、加减速、限位和工具控制；Z轴只承担短行程升降。
- 小屏显示状态，HDMI显示视觉证据。
- 支持确认启动、正常暂停、故障复位和硬件急停。
- 支持MCU心跳超时、回零/运动超时、限位异常和抓取失败处理。
- 标准数字块连续100次搬运成功率不低于98%。

### 0.2 第一版明确不做

- 不做运动物体高速追踪和在线拦截。
- 不做多轴插补曲线、G代码或完整IEC 61131-3运行时。
- 不让MCU软件直接翻转STEP脉冲。
- 不在执行过程中随每帧识别结果实时重规划。
- 不用开发板排针给电机或电磁铁供电。
- 不在MCU工具链尚未跑通时同时接入机械系统。
- 不自行切割铝板、铝型材或亚克力，不依赖3D打印件，不制作洞洞板或定制接口PCB。

| 阶段 | 当前状态 | 已有证据 | 尚缺的阶段门证据 |
|---|---|---|---|

## 3. 套装化电源树与安全回路

### 3.1 电源树

```text
带过载保护的成品插线板
  ├── FPGA原配电源 → HX1P35A（始终独立供电）
  ├── 显示器/补光灯原配电源
  └── GST160A24-R7B封闭式适配器 → 24V
        │
        └── 成品24V急停电源盒（保险、自锁蘑菇头）
              │
              └── 一进四出保险分配盒
                    ├── X轴DM320T
                    ├── Y轴DM320T
                    ├── Z轴DM320T
                    └── DFR0457 → 24V P25/20电磁铁

24V急停后另一路非动力分支 → DFR0831 → +5V_LOGIC
                                     └── DM320T PUL+/DIR+与ULN模块

FPGA开发板：始终使用原配电源独立供电。
```

### 3.2 接地与0V

- 市电只进入有CCC/CE认证的成品插线板和封闭式适配器，团队不拆开适配器。
- GST160A24使用其原装三芯AC线，保护地由适配器内部处理。
- 24V动力0V在保险分配盒处汇聚，三台驱动器分别引线，不串接。
- FPGA GND、DFR0831 GND和ULN模块GND在接口端子处单点连接。
- 3018金属机架不作为任何信号回线。

### 3.3 安全回路

推荐接法：

1. 购买已经完成内部接线的24V急停控制盒，额定直流电流≥10A，带可更换保险和一路无源辅助触点。
2. GST160A24的24V输出接控制盒输入，控制盒输出接四路保险分配盒。
3. 三台DM320T和DFR0457分别接独立保险输出。
4. 急停辅助NC触点接FPGA `ESTOP_FB`，FPGA内部再做同步、去抖和故障锁存。
5. 急停按下后，三台驱动器和电磁铁必须失电；FPGA、摄像头、小屏和HDMI继续显示故障。
6. 恢复急停后不得自动运动，必须执行“清故障→重新回零→人工确认”。

下单前要求商家提供急停盒内部接线图、触点直流额定值和保险规格。只写“220V/10A”但没有直流触点额定值的产品不购买。

### 3.4 原装控制器的使用边界

3018随附GRBL控制板只用于到货机械验收：点动XYZ、检查电机线序、检查限位和排除机械卡滞。完成验收后拔下它与三台电机、限位开关、主轴的连接并贴封条。比赛bitstream运行时，运动脉冲必须来自FPGA `motion_engine`；否则不能宣称FPGA完成硬实时运动控制。

## 5. 信号接口具体连接

### 5.1 FPGA到DM320T

三台DM320T按“5V共阳、开集电极”方式连接。FPGA输出进入带输入下拉的成品ULN2803端子模块，由模块下拉驱动光耦输入：

```text
GPIOA_0 X_STEP ─► ULN2803 IN1 / OUT1 ─► X-DM320T PUL-
GPIOA_1 X_DIR  ─► ULN2803 IN2 / OUT2 ─► X-DM320T DIR-
GPIOA_2 Y_STEP ─► ULN2803 IN3 / OUT3 ─► Y-DM320T PUL-
GPIOA_3 Y_DIR  ─► ULN2803 IN4 / OUT4 ─► Y-DM320T DIR-
GPIOA_4 Z_STEP ─► ULN2803 IN5 / OUT5 ─► Z-DM320T PUL-
GPIOA_5 Z_DIR  ─► ULN2803 IN6 / OUT6 ─► Z-DM320T DIR-

+5V_LOGIC ───────────────────────────────► 三台DM320T的PUL+和DIR+
FPGA GND ────────────────────────────────► ULN2803模块GND
```

- 购买时确认ULN模块每路已有输入下拉；断开FPGA后所有OUT均不得导通。
- ULN2803的`COM`脚悬空；这里驱动的是DM320T内部光耦，不使用续流端。
- PUL+、DIR+只接`+5V_LOGIC`，不得接24V；ENA端第一版不连接。
- FPGA逻辑高令ULN导通，即驱动器光耦有效；RTL中的STEP保持高脉冲语义。
- DM320T要求的最小脉宽和DIR建立时间均为7.5µs，本项目统一设置STEP高/低各≥10µs、DIR提前≥20µs。
- 硬急停由成品急停盒切断三台驱动器24V，不能依赖FPGA输出状态。

### 5.2 3018电机到DM320T

不要依据通用NEMA17线色猜测线圈。先用原装GRBL板确认XYZ均能正确动作，再给三条电机线贴`X/Y/Z`标签。断电后使用万用表找出每台电机的两组线圈，并通过JST-XH成品转接线接到对应DM320T的A+/A-/B+/B-。驱动器带电时严禁插拔电机线。

### 5.3 原点与限位开关

沿用3018套件已经安装好的XYZ机械微动开关和JST线束。每轴第一版只选择回零方向的一只开关，按“FPGA 3.3V上拉—开关闭合到GND”的干接点方式连接；RTL使用两级同步和10ms数字去抖。收到套件后先用万用表确认开关是NO还是NC，再决定有效电平，不根据线色猜测。

### 5.4 Z轴升降与免加工吸头

1. 保留3018原装主轴及ER11夹头作为机械夹具，但物理拔掉主轴电源线。
2. 在ER11中换装4mm夹头。
3. 将M4×40全牙螺柱旋入P25/20背面M4孔，使用薄螺母锁紧。
4. 用ER11夹住螺柱上端，使磁铁吸附面保持水平。
5. 在Z轴全行程内手动移动检查，不得碰床面、数字牌和摄像头线。

Z轴软件设置独立的小速度、小加速度和软限位。回零后只允许在标定的`Z_SAFE`与`Z_PICK`之间运动；任何任务都不得调用主轴输出。

### 5.5 电磁铁

```text
+24V急停后 ─────────► DFR0457 VIN+
24V_GND ─────────────► DFR0457 VIN-
DFR0457 OUT ─────────► 24V P25/20电磁铁
GPIOA_6 MAGNET_EN ───► DFR0457 SIG
FPGA GND ───────────► DFR0457逻辑GND
```

电磁铁线圈两端按厂家极性并联续流二极管，首次测试用示波器检查关断尖峰。PL中增加独立硬件计数器，单次连续通电超过2秒立即关闭并锁存`TOOL_TIMEOUT`。

### 5.6 MCU调试串口

开发板已经板载USB-UART，原理图/手册给出的PH1P35封装脚为`RXD=J1`、`TXD=H1`，优先使用板载Type-C直接输出MCU UART0日志，不再占用40Pin扩展口，也无需购买外置串口板：

```text
MCU uart0_tx → 顶层 O_mcu_uart_tx → PH1P35 H1 → 板载USB-UART RX
MCU uart0_rx ← 顶层 I_mcu_uart_rx ← PH1P35 J1 ← 板载USB-UART TX
```

在`pin.adc`中新增H1/J1的LVCMOS33约束。UART0默认115200、8N1。只有板载USB-UART被其他功能占用或需要第二路独立日志时，才接Waveshare FT232；其VCCIO必须置3.3V，且不用它反向给开发板供电。

### 6.1 分层规则

- `bsp`只负责寄存器和中断，不包含业务规则。
- `services`把硬件抽象为“获取视觉快照”“提交运动命令”“刷新屏幕”。
- `app`只使用服务接口，不直接写APB地址。
- ISR只清硬件标志并设置事件位，不做排序、路径规划或屏幕刷新。
- RTL和固件必须共享同一个`IP_VERSION`与寄存器定义来源；修改寄存器后必须同时升级版本。

## 7. 步骤级软件实施与阶段门

所有阶段必须按顺序执行。每阶段只有在“验收标准全部通过”后才能进入下一阶段；失败时留在当前阶段定位，不允许通过临时屏蔽错误继续向下堆功能。

### 阶段S0：冻结视觉基线

目标：证明引入MCU前，现有视觉工程有可回退的稳定基线。

步骤：

1. 保存当前可工作的bitstream、工程文件和综合/布局布线报告。
2. 记录TD版本、开发板版本、摄像头版本和当前拨码设置。
3. 固定一组8目标测试图，保存HDMI画面和UART输出。
4. 连续运行30分钟，记录目标数、类别和坐标是否稳定。
5. 给当前状态打Git标签或至少生成只读备份。

验收标准：

- 上电后摄像头、DDR和HDMI连续工作30分钟。
- 8目标识别输出与当前显示一致。
- 当前工程可以从干净副本重新生成bitstream。
- 保存当前资源利用率、WNS和主要时钟报告。

进入S1的准则：以上全部通过且基线可恢复。若当前工程本身不能稳定运行，先修复视觉基线，不接MCU。

### 阶段S1：取得并验证MCU工具链

目标：单独证明片内MCU能够编译、下载、启动和输出日志。

步骤：

1. 以已经跑通的`FPGA_MCU/MCU_FPGA`硬件工程和`FPGA_MCU/application/MCU_FPGA_CONNECT`固件工程为唯一参考基线，不再重新猜测SDK、链接脚本或下载配置。
2. 在视频工程中使用同版本`MCU_PLL`和`RISCV_F6F1D1P0_0`生成IP，不手改其底层生成文件。
3. MCU使用独立300MHz `core_clk`和100MHz `timer_clk`；保持摄像头、DDR、HDMI原有时钟结构不变。
4. 先烧录当前合并bitstream，只验证时钟、复位、JTAG和板载UART0；AHB/APB在本步保持空闲。
5. 固件循环输出构建版本、复位原因和1ms Tick计数，同时确认摄像头识别、HDMI和小屏不退化。
6. 执行50次冷启动和50次复位测试，并保存成功次数和失败现象。
7. 修复或隔离当前setup违例，使最终全局WNS≥0；不得因为bitstream能够生成就忽略时序失败。

验收标准：

- 编译、链接、下载命令可重复执行并有脚本或操作记录。
- UART稳定输出115200 8N1，无乱码。
- 1ms Tick在示波器/日志测量误差范围内正确。
- 50次冷启动和50次复位全部成功。
- MCU复位时不会影响摄像头、DDR、识别、HDMI和小屏。
- 合并工程最终setup/hold WNS均≥0。

进入S2的准则：合并bitstream烧录后，视频链路和MCU日志可以同时稳定运行，50次冷启动/复位通过且时序收敛。当前已完成工具链和编译，但尚未取得这些合并板测证据。

### 阶段S2：APB最小闭环

目标：在不猜测片内原生APB绝对基址的前提下，先通过已知CPU AHB窗口可靠访问FPGA内部APB寄存器。

步骤：

1. 将独立工程中已存在的`fpga_apb_bridge.v`和`fpga_apb_regs.v`移入视频工程的MCU子系统，不重新设计第二套协议。
2. 把`RISCV_F6F1D1P0_0`的AHB主接口接到邮箱桥；CPU继续使用已经验证的`0x80000100`邮箱窗口，由桥在FPGA 50MHz域发起真实APB事务。
3. 保留APB内部20位字节地址；原生MCU APB绝对CPU基址没有厂商证据前不作为主路径。
4. 第一轮完全复用`FpgaApbTest()`：检查`IP_ID`、版本、四字节通道、非法/未对齐地址、只读写保护、10000次SCRATCH读写和100次IRQ源轮询。
5. UART只有打印`STAGE_B PASS`后，才继续原有加法回归或VisionPLC寄存器扩展。
6. 保存串口完整日志、显示结果和一次逻辑分析/仿真波形。

验收标准：

- `IP_ID == 0x56504C43`。
- 10000次32位读写零错误。
- 四种字节写掩码行为正确。
- 非法地址有明确错误日志，MCU仍能继续运行。
- IRQ源置位、屏蔽、清除的100次轮询测试通过；这一步不宣称CLIC ISR已经通过。
- UART明确输出`STAGE_B PASS`。
- APB逻辑不引入新的视频关键路径违例。

进入S3的准则：合并视频工程在板上依次输出`STAGE_B PASS`和`VISIONPLC MCU READY`，APB自检连续运行10分钟零错误，并保存板上日志。当前代码已就绪，等待用户综合、烧录和采集日志。

### 阶段S3：中断和MCU心跳安全

目标：建立MCU与PL的事件通道，并证明MCU卡死时输出能自动进入安全态。

步骤：

1. 分配`IRQ_VISION`、`IRQ_MOTION_DONE`、`IRQ_FAULT`和`IRQ_SCREEN_DONE`。
2. 实现`IRQ_STATUS`、`IRQ_ENABLE`和写1清除。
3. MCU每50ms向`HEARTBEAT`写入递增值。
4. `safety_guard`在200ms内没有检测到变化时锁存`MCU_TIMEOUT`。
5. 先用LED或测试引脚代替真实驱动器使能。
6. 人为让固件进入死循环、屏蔽定时中断和按住MCU复位。

验收标准：

- 每个中断触发一次只进入一次ISR，无中断风暴。
- ISR平均执行时间可测且不执行长任务。
- 停止心跳后`200ms±20ms`内安全输出关闭。
- MCU复位期间安全输出始终关闭。
- 必须显式清故障并重新ARM才能恢复。

进入S4的准则：三种MCU失效注入均能硬件关断，且恢复流程正确。

### 阶段S4：视觉原子快照CDC

目标：让MCU得到同一批次的完整8目标结果。

步骤：

1. 在视觉批次完成时冻结8个目标的类别、有效位和坐标。
2. 实现源域`req_toggle`和APB域`ack_toggle`握手。
3. APB域检测请求后等待至少2个周期再复制稳定总线。
4. 成功复制后递增`VIS_SEQ`并产生视觉中断。
5. MCU采用`seq_before/read_all/seq_after`方式读取。
6. 编写仿真，随机化两个时钟相位、目标数和坐标。
7. 板上将MCU日志与HDMI叠加结果逐批对照。

验收标准：

- 仿真至少100000次随机跨域事务无撕裂、丢批或重复批次。
- 板上连续10000个快照中，MCU类别/坐标与HDMI同批数据一致。
- MCU处理不过来时只报告明确的`VISION_OVERRUN`，不静默覆盖。
- 视频链路帧率和显示功能不退化。

进入S5的准则：完成10000快照板上测试且无数据一致性错误。

### 阶段S5：MCU视觉服务与任务规划

目标：在不接电机的情况下完成稳定判定、坐标变换和指令生成。

步骤：

1. 编写`vision_service`，按X中心排序有效目标。
2. 连续3批目标数量和类别一致、对应中心位移≤8像素时置`stable`。
3. 编写Q16.16仿射变换函数。
4. 使用人工注入的4～6个标定点验证像素到毫米坐标。
5. 编写`planner`，生成`HOME/MOVE/TOOL/WAIT/END`内部指令。
6. 先在PC或MCU日志中打印完整执行计划，不提交真实运动命令。
7. 覆盖0、1、8个目标、重复数字、越界坐标和识别变化等情况。

验收标准：

- 非稳定目标绝不生成执行计划。
- 同一快照重复处理得到完全相同指令序列。
- 越界坐标被拒绝并产生错误码。
- 4～6个标定点的回算误差目标≤2mm。
- 合成测试覆盖所有操作码和异常分支。

进入S6的准则：用合成视觉输入完成至少1000组计划测试，零越界运动命令。

### 阶段S6：单轴运动RTL仿真

目标：在无外部硬件条件下验证STEP/DIR、加减速、位置和命令邮箱。

步骤：

1. 实现单轴`stepper_axis`和单在途命令邮箱。
2. MCU先写参数，最后写`CMD_COMMIT`。
3. PL锁存完整参数并更新`ACCEPTED_SEQ`。
4. 完成后更新`DONE_SEQ`并产生中断。
5. 实现速度、加速度、软限位和停止逻辑。
6. 仿真正向、反向、零距离、短距离、停止和重复序号。

验收标准：

- 一个命令序号只执行一次。
- STEP高/低电平均≥10µs。
- DIR变化到首个STEP≥20µs。
- 实际脉冲数等于目标步数，正反向计数正确。
- 急停和心跳超时优先级高于普通命令。
- 越过软限位的命令在发出STEP前被拒绝。

进入S7的准则：RTL仿真覆盖率和所有边界用例通过，保存波形作为团队评审证据。

### 阶段S7：成品接口模块与无电机波形测试

目标：确认3.3V FPGA输出经过成品ULN2803端子模块后，满足三台DM320T的5V共阳输入要求。

步骤：

1. 先不连接DM320T，单独给DFR0831和ULN2803模块供电，检查`+5V_LOGIC`及模块GND。
2. 断开FPGA信号线，确认ULN模块六路输出均不导通；否则退换模块。
3. 用测试bitstream让X/Y/Z三路依次输出1Hz、100Hz、1kHz、10kHz和20kHz STEP，并切换各路DIR。
4. 示波器同时观察FPGA输出与ULN2803输出；ULN输出应相对`+5V_LOGIC`形成极性正确的光耦导通脉冲。
5. 只连接一台DM320T的PUL/DIR控制端，不接24V和电机，复查输入端波形。
6. 分别执行FPGA复位、拔掉FPGA排线、按下急停和5V上下电，确认不会产生伪STEP。

验收标准：

- `+5V_LOGIC`在额定值±5%内，六路输出极性、幅度和脉宽正确。
- 20kHz连续输出10分钟无丢脉冲、明显振铃或串扰。
- STEP高/低均≥10µs，DIR到首个STEP≥20µs。
- FPGA复位、排线断开和接口模块上下电均不产生伪STEP。

进入S8的准则：六路输出全部通过示波器检查，模块断线默认态安全，并保存示波器截图和接线照片。

### 阶段S8：套件到货验收、电源急停与X轴实机

目标：先证明3018机械套件完整可靠，再用一台DM320T接管X轴并完成低速回零。

步骤：

1. 按3018-PROVer V2原厂说明装配；使用随附GRBL控制板依次点动XYZ，检查三轴电机、丝杆、限位、急停和线束，给插头贴`X/Y/Z`标签。
2. 关闭整机电源并拔下原GRBL板与三台电机、限位、主轴的连接；原板装袋保留，不再参与比赛运行。
3. 万用表断电检查24V与0V无短路、四路保险正确；空载测24V和5V，再接电子负载复测5V。
4. 找出X电机两组线圈，通过成品JST延长线接一台DM320T；驱动峰值电流先设为不高于1.3A，微步设8细分。
5. 以最低速度点动X轴1mm、10mm、50mm，方向不对时断电后调整DIR极性，不带电插拔电机线。
6. 接入X_HOME，执行“快速接近→退回→慢速二次接近”回零。
7. X轴往返100次并重复回零20次，运行过程中按下急停验证24V切断和FPGA故障锁存。

验收标准：

- 原装GRBL到货验收中XYZ、限位和急停全部正常，三轴无机械卡滞。
- 24V与5V空载、带载均在额定值±5%内。
- X轴无明显失步、异常啸叫或过热；100次往返后回到起点，误差目标≤0.5mm。
- 回零20次零点极差≤0.5mm。
- 急停后驱动器和电磁铁24V输出断开；独立供电的FPGA继续显示故障。
- 电机、驱动器、适配器和降压模块连续20分钟温度处于器件允许范围。

进入S9的准则：到货验收证据、X轴定位和硬件急停全部通过；任何一次失步或急停失效都必须先定位。

### 阶段S9：XYZ三轴、坐标系和软限位

目标：让FPGA完整接管三轴，建立XY工作坐标和Z轴安全高度。

步骤：

1. 按S8方法分别接管Y轴和Z轴，逐轴确认线圈、方向、电流、微步和原点开关。
2. 完成XYZ三轴“快速接近→退回→慢速二次接近”回零；任一轴超时立即关断并锁存故障。
3. 第一版XY可先顺序移动X后移动Y，不要求同步直线插补；Z轴与XY互锁，Z未到`Z_SAFE`时禁止XY长距离移动。
4. 测量三轴每毫米步数，写入MCU配置；设置机械行程、软限位和至少5mm安全边界。
5. 在空工作台运行XY九宫格定位，每点重复20次；Z轴只在`Z_SAFE`和临时测试高度之间往返。
6. 连续运行XYZ空载循环30分钟，观察拖链、磁铁预留线束和相机排线是否干涉。

验收标准：

- XYZ三轴回零20次均成功，任一轴断开HOME后能超时停机而不撞机械端。
- XY九宫格重复定位误差目标≤1mm；Z轴重复高度误差目标≤0.5mm。
- 任何越界命令都在运动前被拒绝。
- 断电或手动移动后，重新上电必须三轴回零才能接受绝对定位命令。
- 30分钟空载循环无卡滞、松动和线缆拉扯。

进入S10的准则：三轴定位、软限位和Z/XY互锁稳定，全部线束在全行程内无干涉。

### 阶段S10：Z轴磁吸工具端

目标：用3018原装Z轴和免加工吸头完成下降、吸取、抬升和释放。

步骤：

1. 物理拔掉并绝缘包好主轴电机插头，在ER11中换装4mm夹头。
2. 将M4×40螺柱旋入P25/20磁铁并用薄螺母锁紧，再由ER11夹紧；手动检查磁铁端面水平且全行程不碰床面。
3. 接入DFR0457、24V磁铁和续流二极管，空载测试`MAGNET_ON/OFF`，示波器检查关断尖峰。
4. 放置一个成品数字块，低速标定`Z_SAFE`、`Z_PICK`和接近速度；确保钢片能与磁铁端面贴合。
5. 测试`Z_PICK → MAGNET_ON → WAIT → Z_SAFE`和`Z_PICK → MAGNET_OFF → WAIT → Z_SAFE`。
6. 人为让MCU卡死，确认电磁铁2秒硬件超时关闭；按急停确认Z驱动和磁铁同时失电。
7. 连续执行100次原地吸放并记录失败、温升和钢片粘接状态。

验收标准：

- 主轴电机线保持断开，任何软件操作都不能启动主轴。
- Z轴不碰床面、不顶死，磁铁线束在全行程内不拉扯。
- 24V在磁铁吸合时仍在额定值±5%，关断尖峰处于DFR0457与二极管允许范围。
- 电磁铁连续通电超过2秒被PL强制关闭并锁存故障。
- 标准数字块100次原地吸放成功率≥99%，无明显过热和钢片脱落。
- 急停时Z驱动和电磁铁立即失电。

进入S11的准则：工具端独立100次测试通过，没有碰撞、掉压、过热或线束干涉。

### 阶段S11：视觉到机械坐标标定

目标：建立摄像头像素坐标到XY机械坐标的可重复映射。

步骤：

1. 固定摄像头支架，之后禁止移动焦距、高度和角度。
2. 在3018工作台放置至少6个可移除标定贴，覆盖四角和中心；不用加工标定板。
3. 让平台工具中心依次对准每个标定点，记录机械坐标。
4. 读取每个标定点的像素中心。
5. 求解Q16.16仿射系数并写入MCU配置。
6. 使用未参与求解的检查点测量残差。
7. 增加工作区边缘安全裁剪和目标间最小距离检查。

验收标准：

- 独立检查点平均误差≤2mm，最大误差≤3mm。
- 摄像头或底板被移动后，系统能提示“需要重新标定”。
- 超出标定多边形的目标不进入执行计划。
- 两个目标距离过近导致抓取碰撞时，任务被拒绝或提示人工调整。

进入S12的准则：所有检查点达标，标定参数有版本号和校验值。

### 阶段S12：整机闭环和视觉复核

目标：完成识别、计划、搬运、复核和异常重试。

步骤：

1. 放置1个数字块，完成单目标闭环。
2. 扩展到3个，再扩展到8个目标。
3. MCU按规则排序后生成动作程序。
4. 每次抓取前再次确认目标快照仍在允许位置范围内。
5. 放置后重新获取视觉快照，检查源位置是否为空、目标区是否出现对象。
6. 单次失败时允许一次低速重试；第二次失败进入`FAULT_PICK`。
7. 测试重复数字、目标缺失、目标被移动和摄像头遮挡。

验收标准：

- 100次标准搬运成功次数≥98次。
- 任意失败都有明确错误码和当前步骤，不静默跳过。
- 执行期间目标被移动时，系统安全停止或在下一动作前拒绝继续。
- 摄像头断开、视觉快照停止或分类不稳定时不产生新运动。
- 急停、MCU心跳、软限位和工具超时仍全部有效。

进入S13的准则：100次搬运、30分钟循环和全部故障注入通过。

### 阶段S13：小屏、HDMI和比赛演示

目标：让评委在30秒内看懂“看见—思考—执行—验证”。

步骤：

1. HDMI增加目标序号、稳定状态、锁定框和当前执行目标。
2. 小屏显示`SAFE/HOME/READY/PLAN/RUN/VERIFY/FAULT`。
3. 小屏显示目标数量、当前指令、进度、坐标和故障码。
4. 实体按键定义：确认执行、正常暂停、故障复位、模式切换。
5. 准备自动模式和单步讲解模式。
6. 编写固定演示脚本和故障演示脚本。

验收标准：

- 评委改变数字块顺序后，HDMI和小屏内容同步更新。
- 未按确认键绝不动作。
- 正常暂停可恢复；急停必须重新回零后才能恢复。
- 完整演示连续执行10次零人工干预。
- 故障演示不会损坏机构或留下危险输出。

项目完成准则：S0～S13的测试记录、波形、视频、接线图和版本号全部归档，最终bitstream和MCU固件可从干净工程重复生成。

## 8. 上电与停机标准流程

### 8.1 每次上电

1. 检查工作区无手、工具和松动物体。
2. 检查急停处于按下状态。
3. 检查XYZ三轴位于非撞限位置，工作区无松动数字块。
4. 接通FPGA原配电源，确认视觉和小屏启动。
5. 打开成品插线板，检查封闭式24V适配器、急停盒和5V模块指示。
6. MCU自检：IP版本、APB、视觉、传感器状态必须正常。
7. 旋转释放急停。
8. 在小屏确认无故障后按实体“故障复位/ARM”按钮；此按钮只解除PL锁存，不旁路急停。
9. 执行XYZ三轴回零。
10. 系统进入`READY`后才允许放置目标并确认任务。

### 8.2 正常停机

1. 停止当前任务并等待运动结束。
2. 移动到停车位置并关闭电磁铁。
3. 按下急停，使急停盒切断驱动器和电磁铁24V。
4. 关闭成品插线板电源。
5. 最后关闭FPGA开发板电源。

### 8.3 异常停机

遇到碰撞、失步、线缆拉扯、异常声音、冒烟或不可预期运动，直接按急停，不先操作软件。排除故障后必须重新执行上电检查和XYZ三轴回零。

| 编号 | 注入方式 | 预期行为 | 通过标准 |
